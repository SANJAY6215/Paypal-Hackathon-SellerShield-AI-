# Security
Simulations are local and isolated; nothing contacts real merchants or payments. Patches never auto-apply: approve → explicit `confirm` → demo app only → rollback. SSRF: scheme allow-list, blocked hosts, private-IP check at connect time, redirect re-validation, size/time limits. Uploads: allow-listed extensions, 1 MB, UTF-8, never executed. Auth: bcrypt, JWT httpOnly cookie, roles, per-user tenant isolation, rate limits, Helmet, Zod. Audit log of sensitive actions; prompts redacted. Limitations: DNS pinning relies on Node `lookup`; JWT secret must be set in production; in-process jobs.
